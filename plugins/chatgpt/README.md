# AgentJobRelay for ChatGPT Desktop/Codex

Self-hosted experimental plugin marketplace, separate from OpenAI's official directory. Requires a local Linux x86_64/glibc or Windows x86_64 executor and Node.js 20+/npm on the host's PATH. Catalog registration uses Codex CLI and Git; the [Release ZIP route](https://github.com/MorningFrog/agent-job-relay/blob/main/docs/installation.md#install-from-a-github-release-zip) needs no Git. The pinned shared runtime is fetched from the official npm registry on first use, includes the Rust binary and runs no package install scripts. First use requires network access. No Rust compiler or developer checkout is needed.

Install the latest published runtime and matching released marketplace in Bash:

```bash
AJR_VERSION="$(npm view agent-job-relay-runtime@latest version --registry=https://registry.npmjs.org)" &&
codex plugin marketplace add MorningFrog/agent-job-relay --ref "v$AJR_VERSION"
```

After successful registration, restart ChatGPT Desktop and install AgentJobRelay from the **AgentJobRelay** marketplace. Use a new local chat. Installation/UI availability depends on your host version/account. CLI users can use `codex plugin add agent-job-relay@agent-job-relay`; that alone provides no automatic CLI model continuation.

The MCP server and packaged `relay` terminal launcher use the same runtime version and persistent `codex` profile. Default state on Linux is `$XDG_STATE_HOME/agent-job-relay/codex`, else `$HOME/.local/state/agent-job-relay/codex`; Windows uses `%LOCALAPPDATA%\AgentJobRelay\profiles\codex` and the `relay.cmd` terminal launcher. An absolute `AJR_STATE_DIR` overrides it and must match in the ChatGPT Desktop process and terminal. Keep history outside npm/plugin caches. A previous offline installation has a different recorded profile: do not enable both or switch profiles as a repair. Review and explicitly select the original state if migrating.

For a terminal command, install the matching runtime with npm's standard global installation; source 0.1.11 adds `ajr` (awaiting publication), defaulting to this same `codex` profile. Plugin installation alone does not register it. Use `agent-job-relay codex ui` for the embedded browser UI, or ask this plugin to open its task manager without installing a global CLI. See [terminal installation](https://github.com/MorningFrog/agent-job-relay/blob/main/docs/installation.md#terminal-and-web-ui).

Windows normally needs no manual daemon preparation. When Codex's MCP cleanup Job Object blocks direct startup, the native runtime automatically requests a local CIM bootstrap, verifies the same user/integrity/process identity, transfers the caller environment over a private pipe and starts the same profile. No login startup entry, scheduled task or service is installed. Windows PowerShell/CIM must be permitted by local policy; `AJR_WINDOWS_STARTUP=direct` disables the broker. If blocked, run same-profile `daemon start` in an outside terminal. Published-baseline Windows Desktop acceptance uses Full access. New release candidates require their own native/package checks; consult the version-specific evidence before claiming live continuation.

The workflow obtains a fresh binding from the initiating chat's terminal, never from the shared MCP process. Background commands run with your OS permissions. ChatGPT Desktop completion uses an experimental private interface, not a public stability guarantee. Host acceptance does not establish that an Agent resumed; CLI integration provides an inbox only. No telemetry service is added, but npm/GitHub handle package/repository downloads, and the host/model can receive results you explicitly inspect.

For upgrades, finish active jobs and follow the [online update steps](https://github.com/MorningFrog/agent-job-relay/blob/main/docs/updating.md#update-the-online-marketplace): resolve latest, remove the old marketplace registration, add the newly resolved tag, refresh/reinstall the plugin through the host and reconnect MCP. Codex refuses a different tag over an existing registration. An incompatible daemon requires an explicit same-profile stop; no automatic stop, rollback or command replay runs. Host/cache removal preserves external state/history and running jobs. Remove the plugin through the host, then remove the marketplace if no longer wanted. For removal see [uninstallation](https://github.com/MorningFrog/agent-job-relay/blob/main/docs/uninstalling.md); find capability and evidence guides in the [documentation index](https://github.com/MorningFrog/agent-job-relay/blob/main/docs/README.md).
