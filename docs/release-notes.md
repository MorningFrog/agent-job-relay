Experimental Linux/Windows x86_64 plugin delivery candidate. The npm tarballs contain one shared Rust/MCP runtime and the OpenCode V1 bridge; the ZIP contains a self-hosted ChatGPT Desktop/Codex marketplace. See release.json for the exact version, platforms, Linux minimum glibc and package identities; verify SHA256SUMS before use.

Windows adds private SID/DACL pipes, process-instance checks, runner-owned Job Objects, independent daemon/runner lifetimes, bounded output, cancellation/timeouts and data-preserving offline plugin maintenance. Enclosing host jobs must permit breakaway. Codex CLI 0.164.0 MCP requires same-profile `daemon start` from an outside terminal before submission; cold auto-start in its cleanup job refuses explicitly. Windows Desktop UI/observed continuation remains unverified.

OpenCode targets 1.19.4 and is checked on Linux and Windows with the actual loader/session API and a simulated model. Codex 0.164.0 marketplace/MCP discovery on both platforms is checked using a loopback registry serving the unpublished candidate. Neither check establishes a real-provider session or clean Desktop UI installation. Desktop wake remains experimental and uses a private interface. Claude is a separate inbox-only framework requiring community account-backed testing.

These files are candidates, not official plugin-directory listings. The npm account is awaiting verification and package names remain provisional. The repository marketplace's normal online install command works only after the exact runtime npm version is published. Downloading this draft's files does not publish them to npm. New host profiles are separate from previous offline installations; review the recorded state path before migrating. Updates/uninstall never automatically stop a daemon, replay commands or purge history.
