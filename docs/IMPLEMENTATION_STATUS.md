## Release and support boundaries

The public baseline is npm/GitHub **0.1.22**, with metadata/receipt evidence inspected on 2026-11-06 and its original independent check retained above. Source retains version 0.1.23, with later CI migration changes under Unreleased; new unused-version preparation is required after migration. The Actions manual release backend is currently unavailable, and Linux CI does not publish or seal candidates. Its Linux payload requires glibc **2.34** or newer; local developer builds can require a newer glibc and must not replace sealed release payloads. Preserve published CHANGELOG sections/dates, tags, candidate bytes and receipts; changed runtime/package bytes require an unused version and new candidate. A failed verification step does not undo publication. See [release handoff](release.md#current-release-handoff).

Goal wake-up and usually successful pause/resume have user-reported sustained-use evidence, with occasional resume failure still unresolved. Windows goal/controller, direct native confirmation UI, a specifically observed full real-model three-round workflow, goal intermediate feedback/native re-pause, changed-host goal handling and measured long-duration savings need separate qualification. Host goal generation/CAS is unavailable. Actual results completed while Desktop is closed, receiver deduplication and multi-day renewal remain open. Claude account-backed loading, OpenCode real-provider/V2, stronger containment, disk-loss qualification and cross-file install recovery remain in [TODO](TODO.md). No adapter automatically records `confirmed_resumed`.
